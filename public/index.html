    Recreate this layout in Godot JSON reference guide

    Export JSON downloads your layout, including object bounds, center positions in pixels, collision sizes, movement, enemy and trap settings, and ordered route points. Import that file to continue editing.

    Use godot.position_px for the node position and godot.size_px for a centered collision shape. Platforms suggest StaticBody2D; moving platforms suggest AnimatableBody2D; enemies suggest CharacterBody2D; keys, exits, killzones, and traps suggest Area2D. Match your scene's anchor and script as needed.

    This is a design reference, not a .tscn importer. Enemy detection, patrol, damage, and trap timing are settings to recreate in your Godot scripts. Unsaved edits last only while this page stays open. Export before closing or reloading.
